# User Stories - KeepWarm CRM

## User Management

As a **seller**, I want to **log in** to access my customers.

As a **seller**, I want to **log out** to securely end my session.

As an **admin**, I want to **create new sellers** to give them access to the system.

As an **admin**, I want to **edit seller information** to keep data current.

As an **admin**, I want to **view seller details** to see the seller's information.

As an **admin**, I want to **delete sellers** to manage access.

As an **admin**, I want to **manage all sellers** to have full control over the system.

## Customer Management

As a **seller**, I want to **list my customers** to see which ones need follow-up.

As a **seller**, I want to **create a new customer** to start managing the relationship.

As a **seller**, I want to **view customer details** to see all information about the customer.

As a **seller**, I want to **edit customer information** to keep data current.

As a **seller**, I want to **delete a customer** to clean up old contacts.

As an **admin**, I want to **see all customers** in the system to have a full overview.

As an **admin**, I want to **manage all customers** to be able to help sellers.

## Interaction Management

As a **seller**, I want to **see my interactions** for a customer so that I can track previous communications and maintain better customer relationships.

As a **seller**, I want to **log a new interaction** (call, meeting, or email) with date, time, and notes

As a **seller**, I want to **edit my interactions** to update interaction details.

As a **seller**, I want to **delete my interactions** to remove incorrect entries.

As an **admin**, I want to **see all interactions** for any customer to have full visibility.

## Development

As a **developer**, I want to **reset the database and seed all tables** to set up a clean development environment with deterministic test data (not relying on random data or time).
