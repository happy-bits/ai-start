# User Stories - KeepWarm CRM

## Användarhantering

Som **ny användare** vill jag **registrera ett konto** för att komma åt systemet.

Som **användare** vill jag **logga in** för att komma åt mina kunder och interaktioner.

Som **användare** vill jag **logga ut** för att säkert avsluta min session.

Som **admin** vill jag **skapa nya användare** för att ge dem åtkomst till systemet.

Som **admin** vill jag **redigera användarinformation** för att hålla data aktuell.

Som **admin** vill jag **visa användardetaljer** för att se användarens information.

Som **admin** vill jag **ta bort användare** för att hantera åtkomst.

Som **admin** vill jag **hantera alla användare** för att ha full kontroll över systemet.

## Kundhantering

Som **användare** vill jag **lista mina kunder** sorterade på återkomstdatum för att se vilka som behöver uppföljning.

Som **användare** vill jag **skapa en ny kund** för att börja hantera relationen.

Som **användare** vill jag **visa kunddetaljer** för att se all information om kunden.

Som **användare** vill jag **visa kundens interaktionshistorik** för att förstå relationens utveckling.

Som **användare** vill jag **redigera kundinformation** för att hålla data aktuell.

Som **användare** vill jag **ta bort en kund** för att rensa bort gamla kontakter.

Som **admin** vill jag **se alla kunder** i systemet för att ha full översikt.

Som **admin** vill jag **hantera alla kunder** för att kunna hjälpa användare.

## Interaktionshantering

Som **användare** vill jag **skapa en ny interaktion** för en kund för att dokumentera kontakt.

Som **användare** vill jag **sätta återkomstdatum** vid interaktion för att planera nästa kontakt.

Som **användare** vill jag **se att kundens nästa återkomstdatum uppdateras automatiskt** för att hålla koll på uppföljningar.

Som **användare** vill jag **visa interaktioner** för att se historiken.

Som **användare** vill jag **redigera en interaktion** för att korrigera information.

Som **användare** vill jag **ta bort en interaktion** för att rensa bort felaktiga poster.

Som **användare** vill jag **se att återkomstdatum räknas om** när jag tar bort interaktioner för att hålla data korrekt.

Som **admin** vill jag **se alla interaktioner** i systemet för att ha full översikt.

Som **admin** vill jag **hantera alla interaktioner** för att kunna hjälpa användare.
