# Dokumentationsprompts

Denna fil innehåller instruktioner för hur dokumentationsfilerna i `docs/` ska genereras eller uppdateras. Använd dessa prompts när du skapar eller reviderar dokumentation.

---

## databas.md

**Syfte:** Dokumentera databasarkitekturen och drift i KeepWarm-projektet.

**Dessa rubriker ska ingå:**

- Översikt
- Teknisk stack
- Databasschema
- Migrationer
- Konfiguration
- Seed
- Tester

**Format:** Max 200 rader. Använd rubriker, tabeller och kodblock där det underlättar läsbarheten.
